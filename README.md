# College Complaint Management System

## 1. Project Overview

The College Complaint Management System is a Python-based application designed to manage and track student complaints in a college.

Students can submit complaints, view their complaints, and track their status. Administrators can view all complaints, update complaint status, and generate complaint reports.

## 2. Features

- Student Login
- Admin Login
- Submit Complaint
- View My Complaints
- View All Complaints
- Update Complaint Status
- Complaint Reports
- Complaint Categories
- Complaint Priority
- Input Validation

## 3. Functional Modules

### Student Module
- Student login
- Submit complaints
- View submitted complaints
- Check complaint status

### Admin Module
- Admin login
- View all complaints
- Update complaint status
- Generate complaint reports

### Database Module
- Stores complaint information
- Retrieves complaints
- Updates complaint status

### Reports Module
- Generates complaint statistics
- Shows complaint status counts
- Shows complaint priority counts
